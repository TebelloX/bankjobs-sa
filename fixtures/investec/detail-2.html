Mobile App Developer (13804)

Description

The Mobile Developer for Investec Business Online (IBOL) forms part of the Investec Business & Commercial Banking (BCB) division and operates within the BCB IT environment.

This is a hands-on engineering role focused on building, maintaining, securing, and supporting enterprise-grade mobile applications across iOS and Android using React Native, Expo, TypeScript, and modern mobile delivery tooling.

The role contributes to reliable mobile delivery by translating business and design requirements into high-quality technical solutions, integrating with enterprise services, supporting CI/CD and release processes, and maintaining strong engineering discipline across code quality, testing, security, performance, accessibility, and production support.

The Mobile Developer works closely with product owners, designers, QA, backend engineers, platform teams, architecture, and operations to deliver secure, scalable, maintainable, and customer-focused mobile outcomes aligned with Investec BCB priorities

Key Responsibilities

Mobile Engineering Delivery & Execution

  • Build, enhance, and maintain mobile application features across iOS and Android using React Native, Expo, TypeScript, JavaScript, and React fundamentals.
  • Translate business requirements, wireframes, Figma designs, and design-system guidance into polished, accessible, and maintainable mobile user interfaces.
  • Contribute to end-to-end delivery from refinement and development through testing, deployment, release, and post-implementation support.
  • Apply sound engineering judgement when using AI-assisted development tools such as Codex, Cursor, Copilot, or ChatGPT to improve productivity without compromising accountability or quality.

Enterprise Mobile Tooling, Monorepos & Shared Packages

  • Work effectively within mobile monorepos, shared packages, dependency management models, and workspace tooling.
  • Support sustainable mobile architecture by keeping shared components, packages, and platform conventions clean, reusable, and well documented.

CI/CD, Build, Signing & Release Management

  • Support Azure DevOps CI/CD using YAML pipelines, secure files and secrets, automated builds, automated testing, code-signing, and release approvals.
  • Build, sign, distribute, and support mobile applications through App Store Connect, TestFlight, Google Play Console, and approved internal distribution channels.
  • Contribute to reliable release processes, versioning discipline, environment readiness, and release evidence required for enterprise governance.

Integration, Security & Enterprise Services

  • Integrate mobile applications with RESTful APIs, authentication flows, secure storage, and enterprise backend services.
  • Apply good mobile security practices, data privacy awareness, and secure coding principles in line with banking and internal governance expectations.
  • Identify and escalate technical risks, integration constraints, security considerations, and operational dependencies early.

Quality Engineering, Observability & Production Support

  • Contribute to automated testing, TDD/BDD practices, mobile quality gates, code review, and defect prevention.
  • Improve mobile performance, accessibility, observability, maintainability, and resilience across production applications.
  • Support production incidents, diagnostics, root-cause analysis, and continuous improvement of mobile reliability.

Agile Collaboration & Engineering Discipline

  • Work within Agile/Scrum delivery practices, contributing to sprint planning, backlog refinement, reviews, retrospectives, and transparent progress tracking in Azure DevOps.
  • Demonstrate strong Git discipline, clear pull requests, constructive code reviews, and accountability for the quality of software shipped.

• Collaborate effectively with product, design, QA, backend, platform, architecture, and operations stakeholders.

Qualifications, Experience and Skills

ESSENTIAL TECHNICAL KNOWLEDGE

  • Strong React Native, Expo ecosystem, and TypeScript experience.
  • Strong JavaScript and React fundamentals, including modern state management and navigation patterns.
  • Experience building and maintaining iOS and Android apps in enterprise environments.
  • Experience using error and analytics tools like Dynatrace/Sentry/Splunk.
  • Strong understanding of monorepos, shared packages, dependency management, and mobile workspace tooling.
  • Experience with Azure DevOps CI/CD, including YAML pipelines, secure files/secrets, automated builds, testing, signing, and release approvals.
  • Practical experience building, signing, distributing, and supporting mobile apps through App Store Connect, TestFlight, Google Play Console, and internal distribution channels.
  • Experience integrating with RESTful APIs, authentication flows, secure storage, and enterprise backend services.
  • Good understanding of mobile security, performance, accessibility, observability, and production support.
  • Experience with automated testing, TDD/BDD practices, and mobile quality gates.
  • Ability to implement polished UI from Figma, wireframes, and design systems.
  • Strong Git, code review, Agile/Scrum, and engineering delivery discipline.
  • Comfortable using AI-assisted development tools such as Codex, Cursor, Copilot, or ChatGPT to improve productivity while maintaining accountability, code quality, and sound engineering judgement.

DESIRABLE SKILLS

  • Native iOS/Android experience with Swift/Kotlin or native module development is advantageous.
  • Azure certifications such as AZ-900, AZ-204, or AZ-400 are advantageous.
  • Experience in Digital / Online Banking channels and platforms is advantageous.
  • Understanding of payments, foreign exchange, lending, and other transactional banking products is advantageous.

SUMMARY PROFILE

We are looking for a modern mobile engineer who can work confidently across React Native, Expo, TypeScript, enterprise CI/CD, mobile distribution, and production support. The ideal candidate uses AI tools intelligently to accelerate delivery, but still demonstrates strong fundamentals, ownership, security awareness, and accountability for the software they ship.
